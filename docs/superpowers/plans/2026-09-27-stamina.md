- [ ] **Step 1: Config**

```ts
export const FITNESS = {
  RECOVERY_BASE: 0.35,          // fraction of the missing fitness recovered per rest day
  AGE_FACTOR: [ [24, 1.1], [28, 1.0], [32, 0.85], [Infinity, 0.7] ] as [number, number][],
  LOAD_HALF_LIFE_DAYS: 4,
  LOAD_HIGH: 220,               // ≈ 3 full matches in ~7 days
  LOAD_RECOVERY_PENALTY: 0.5,   // at LOAD_HIGH recovery rate × (1 − 0.5)
  LOAD_DRAIN_BONUS: 0.25,       // at LOAD_HIGH in-match cost × 1.25
  HEAVY_TRAINING_LOAD: 10,
  STAMINA_RECOVERY: { base: 0.9, span: 0.2 },  // × (0.9 + 0.2 × stamina/10)
} as const;
```

- [ ] **Step 2: Testes** (`fitness.test.ts`), escritos primeiro:
  - `postMatchFitness(endEnergy)` = energia final arredondada, clamp 0..100.
  - `recoverDay(fitness, { age, load, stamina })`: 55 → ~81 → ~88 → ~93 em 3 dias (26 anos, carga 0,
    stamina 7; tolerância ±1,5); recuperação menor com carga ≥ `LOAD_HIGH` (metade da taxa) e com
    idade > 32; nunca passa de 100; monotônica.
  - `decayLoad(load, days=1)`: meia-vida de 4 dias (`decayLoad(100, 4) ≈ 50`).
  - `addMatchLoad(load, minutes)` soma os minutos; `addTrainingLoad(load, intensity)` soma
    `HEAVY_TRAINING_LOAD` só no treino pesado.
  - `drainMultiplier(load)` = 1 com carga 0, 1,25 com carga ≥ `LOAD_HIGH`, linear entre.
- [ ] **Step 3: Implementação** (funções puras, sem I/O):

```ts
export function ageRecoveryFactor(age: number): number;
export function loadRecoveryFactor(load: number): number {  // 1 − 0.5 × min(1, load/LOAD_HIGH)
  return 1 - FITNESS.LOAD_RECOVERY_PENALTY * Math.min(1, Math.max(0, load) / FITNESS.LOAD_HIGH);
}
export function staminaRecoveryFactor(stamina: number): number;
export function recoverDay(fitness: number, p: { age: number; load: number; stamina: number }): number {
  const rate = FITNESS.RECOVERY_BASE * ageRecoveryFactor(p.age) * loadRecoveryFactor(p.load) * staminaRecoveryFactor(p.stamina);
  return Math.min(100, fitness + (100 - fitness) * rate);
}
export function decayLoad(load: number, days = 1): number;
export function addMatchLoad(load: number, minutes: number): number;
export function addTrainingLoad(load: number, intensity: "light" | "normal" | "heavy"): number;
export function drainMultiplier(load: number): number;
export function postMatchFitness(endEnergy: number): number;
```
