# Árbitros com nome, rigor e rosto (4.17) — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** cada país tem um quadro de árbitros e assistentes (reais do Wikidata, completados com nomes gerados do
livro da comissão); toda partida de liga, copa e continental recebe um árbitro e dois assistentes por uma escala
determinística (os melhores nos jogos grandes, descanso, rodízio, continental de outro país); o rigor do árbitro mexe um
pouco nas faltas e nos cartões do motor e do quickSim sem mudar o volume do mundo; o árbitro aparece com rosto, nome e
bandeira na prévia, no Resumo, no resultado e no campo; a aba Árbitros de Estatísticas mostra os cartões por árbitro.

**Architecture:** dado real em `src/example_data/referees.json` (gerado por `scripts/fetchWikidataReferees.ts`); lógica
pura em `src/Domain/referees/` (quadro, qualidade, rigor, renovação, importância, escala, estatísticas);
`src/backend/refereeWorld.ts` é a única E/S (`saves/{id}/referees/pool.json` e `state.json`, bufferizados). O motor lê
`GameState.referee`, o quickSim `QuickSimInput.refereeStrictness`; s = 0 / ausente reproduz o jogo de antes número a
número.

**Decisões do usuário (2026-10-09):** rigor real do Transfermarkt (spec §1.3, Task 1b), árbitras incluídas, Reino Unido na Inglaterra, faixa de rigor sempre visível, base sem árbitro.

**Tech Stack:** Bun + TypeScript, React 19 + Tailwind, Pixi v8, facesjs (só no servidor).

import { refereeFoulMult, refereeRedMult, refereeYellowMult, strictnessBand, strictnessOf } from "@/Domain/referees/strictness";

describe("referee strictness", () => {
  test("neutral is exactly 1", () => {
    for (const f of [refereeFoulMult, refereeYellowMult, refereeRedMult]) { expect(f(0)).toBe(1); expect(f(undefined)).toBe(1); }

    expect(Math.max(...xs)).toBeLessThanOrEqual(1);

  });
  test("bands", () => {
